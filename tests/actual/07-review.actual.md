## 1. STE rewrite

1. Do not use the bypass.
2. Make sure that the yellow valve is open.
3. Before you start, do a check of the valve.

## 2. Findings

| Location | Non-STE wording | Rule | Fix |
|---|---|---|---|
| Sentence 1 | Don't | 4.2 | Write Do not. Do not use contractions. |
| Sentence 1 | utilize | 1.1 | Write use. |
| Sentence 1 | semicolon | 8.1 | Do not use a semicolon. Split the sentence. |
| Sentence 1 | ensure the valve is open | 1.1, GR-1 | Write Make sure that the valve is open. |
| Sentence 1 | two commands in one sentence | 5.2 | Write one instruction in each sentence. |
| Sentence 1 | e.g. | GR-6 | Do not use Latin abbreviations. Identify the yellow valve. |
| Sentence 1 | the yellow one | GR-3, 4.5 | Repeat the noun. Write the yellow valve. |
| Sentence 1 | etc. | GR-6 | Do not use etc. Stop the list. |
| Sentence 2 | You must perform | Section 5, 1.1 | Do not write you must before an ordinary command. Write Do a check of. |
| Sentence 2 | it | GR-3 | The pronoun can attach to the bypass or the valve. Repeat the noun (the valve). |
| Sentence 2 | prior to start | 1.1, 3.7, 4.2 | Write before you start. Do not use start as a noun of action. |

## 3. Word-count flags

No sentence is more than 20 words.

- Sentence 1: 14 words (if the semicolon is read as one sentence).
- Sentence 2: 10 words.
