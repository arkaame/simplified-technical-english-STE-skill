# 05 technical verbs — expected properties

Mode: write/convert. Text type: procedure.

Must:

- Prefer approved verb + technical noun over a technical verb
- `Grease the fasteners` → `Apply grease to the fasteners`
- `Clamp the cable` → a construction with clamps, not CLAMP as a verb unless it is the only accurate process verb
- `detect` is a technical verb for a device; for a person, use `find`
- Keep `repair`
- Do not invent a grease type or a clamp part number

Gold rewrite:

1. Apply grease to the fasteners.
2. Put clamps on the cable to hold it in position.
3. If you find broken wires, repair them.
