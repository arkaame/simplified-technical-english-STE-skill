# 01 procedure — expected properties

Mode: write/convert. Text type: procedure.

Must:

- No contractions
- Imperative steps
- One instruction per sentence (the pump ON and pressure check are not simultaneous)
- `do a check of`, not `perform` or `check` as a verb
- `Make sure that`, not `ensure` or `verify`
- `Set ... to ON`, not `turn on`
- `stop`, not `terminate` / `should`
- Each sentence 20 words or fewer by Section 8 counting
- Keep the oil, drain valve, fuel pump, pressure, and leakage meaning
- Do not invent a pressure value

Gold rewrite:

1. Before you start the engine, do a check of the oil level.
2. Make sure that the drain valve is closed.
3. Set the fuel pump to ON.
4. Make sure that the pressure is shown.
5. If you see leakage, stop the test immediately.
