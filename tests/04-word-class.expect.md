# 04 word class — expected properties

Mode: write/convert. Text type: procedure.

Must:

- TEST is a noun, not a verb → `Do a test of the system`
- FOLLOW for instructions → `Obey the safety instructions` (FOLLOW means come after)
- CHECK is not used as a verb → `Do a check of the laptop battery`
- Imperative
- No invented test method, spec, or limit

Gold rewrite:

1. Do a test of the system.
2. Obey the safety instructions.
3. Do a check of the laptop battery.
