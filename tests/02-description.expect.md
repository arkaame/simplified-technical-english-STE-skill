# 02 description — expected properties

Mode: write/convert. Text type: description.

Must:

- No continuous or perfect verb forms (`is being monitored` is not permitted)
- Active voice
- No imperative
- Noun-of-action rebuilt (`removal` → `remove`, `inspection` / `accomplished` rebuilt)
- `-ing` only as a noun or as a modifier, or rewritten as a `when` / `if` clause
- Each sentence 25 words or fewer
- Paragraph has one topic and six sentences or fewer
- Do not invent a risk that the source did not state; keep "dangerous" rather than upgrading it to injury

Gold rewrite:

The control unit monitors the hydraulic pump.

Before you remove the cover, you do an inspection of the filter.

If a person opens the bypass valve, this can be dangerous.
