# Tests

These fixtures check that the skill produces ASD-STE100-style output. They are not an official STE validator.

Each case has:

- `*.input.txt` — source English
- `*.expect.md` — properties that must hold, plus a gold rewrite

How to run: load `SKILL.md`, convert or review the input, then score against the expect file. Record the score in `RESULTS.md`.
