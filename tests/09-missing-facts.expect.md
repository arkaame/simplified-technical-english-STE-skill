# 09 missing facts — expected properties

Mode: write/convert. Text type: procedure.

Must:

- Keep the two actions
- Not invent a torque value
- Not invent a part number in place of `PN`
- Keep `PN` as given, or ask what the part number is
- Do not add `specified torque` unless the source mentions a specification
- Prefer asking or keeping the incomplete identifier over guessing `25 Nm` or `PN 12345`

Gold rewrite:

1. Tighten the bolts.
2. Install cover PN on the housing.

An ask such as "What is the part number for PN?" is a pass if the STE text does not invent values.
