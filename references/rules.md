# STE writing-rule notes (ASD-STE100 Issue 9)

Use this file when SKILL.md is not enough. Keep the official meaning. Do not add style that the standard does not require.

## Words (1.1–1.14)

A technical noun names a specified concept in a subject field (engine, corrosion, hangar). A technical verb names a specified process in a subject field (ream, solder, download).

If a word is in the dictionary as unapproved, you still may use it when it is a technical noun in context. Example — base is unapproved for "bottom surface" (`bottom` is the alternative), but base is permitted as a geometry term or a facility.

FOLLOW means "come after / go after." Do not write `Follow the safety instructions.` Write `Obey the safety instructions.`

CHECK is not an approved verb in the usual dictionary sense. Write `Do a check of the laptop battery.`

Colors are treated as technical nouns. Do not write blacker or the reddest.

Use one name for one item in the whole topic. If the approved name is actuator, do not switch to servo control unit or control unit.

## Multi-word nouns (2.1–2.2)

The last word is the head noun. More than three words hides the head.

Bad — runway light connection resistance calibration
Better — Write the full name once. Then use calibration or connection-resistance calibration.

Hyphens show a unit — flight-control computer, self-locking nut.

## Verbs (3.1–3.7)

Approved verb card example:

- REMOVE / REMOVES / REMOVED / REMOVED
- GIVE / GIVES / GAVE / GIVEN

Past participle as adjective is permitted — a damaged seal, the disconnected hose.

-ing is not a tense. Opening a door can be dangerous uses opening as a noun. A mechanic opening a door... is not permitted as a reduced clause. Write When a mechanic opens a door...

Do not write The test can be continued. Write Continue the test.

Do not write Before the removal of the unit. Write Before you remove the unit.

## Sentences (4.1–4.5)

Do not drop articles, subjects, or `that` to save words. Do not write `Ensure valve open.` Write `Make sure that the valve is open.`

Use a vertical list when a sentence holds several items, alternatives, or results.

Connecting words are traffic signs. Use them between related sentences, not as decoration.

## Procedures (5.1–5.5)

Number or letter the work steps.

Two actions in one sentence only when they are simultaneous — Hold the panel in its open position and install the fastener. Cut and remove the wire. Remove and discard the seal.

A result that occurs immediately after the action can stay in the same work step — Measure the leakage from the outlet port. The leakage must not be more than 0.5 cc/minute.

Condition first — If the CSD does not operate correctly, disconnect it from the gearbox.

A note that contains an imperative is a work step. Move it into the procedure and number it.

## Description (6.1–6.6)

Start with what the item is and what it does. Then add parts, then operation, then limits.

Repeat key nouns so the reader can follow the chain — system, localizer, glideslope.

One topic per paragraph. Stop at six sentences.

## Safety (7.1–7.3)

Do a risk analysis before you label the instruction. Cleanliness of oxygen tubes is a WARNING, not a CAUTION, because oxygen plus grease can explode.

Do not write an abstract statement. Write the action that decreases the risk, then the injury or damage that can occur.

STE does not specify uppercase. Follow the publication specification the user names.

## Punctuation and count (8.1–8.7)

No semicolon.

Parentheses uses — valve (10, Figure 1); nuts (74); (1) Install...; Liquid Crystal Display (LCD); component(s); increase the pressure slowly (not more than 10 psi each minute); left (right) access panel L42 (R42).

Word-count example — Make sure that the EMER pushbutton switch is released (the EMER legend is off). Outer sentence = 10 words because the parenthesis counts as one word. Inner sentence = 5 words.

6 mm counts as one word. twenty-one counts as one word. In-Flight Entertainment (IFE) System counts IFE as one word.

## Construction (9.1–9.4 and GR)

If the dictionary alternative changes meaning, do not use it. Just → immediately is wrong when just means only.

If the needed word is absent, rebuild the sentence. Incidence of water in fuel → Water in fuel is dangerous. Clears the track locks → until it is away from the track locks.

Do not manufacture phrasal verbs. If the two-word verb is not approved, use a single approved verb or a technical verb from Rule 1.12.

Same lubrication step must not appear once as lubricate the bolts and later as apply a small quantity of oil to the threads unless those are truly different tasks.
