# STE delivery checklist

Run this pass on every draft before you return it.

## Words

- [ ] Every word is an approved dictionary word, a technical noun, a technical verb, or quoted text
- [ ] Each approved word keeps its dictionary part of speech
- [ ] Each approved word keeps its approved meaning
- [ ] Technical nouns are not used as verbs
- [ ] Technical verbs are not used as nouns
- [ ] One item has one name through the topic
- [ ] No slang, jargon, or regional wording
- [ ] American English spelling unless a directive says otherwise

## Verbs and sentences

- [ ] Only infinitive, imperative, simple present, simple past, simple future, or past participle as adjective
- [ ] No continuous, perfect, or stacked auxiliary forms
- [ ] -ing appears only as a technical noun or a modifier in one
- [ ] Active voice, unless the agent is unknown in description
- [ ] Actions use verbs, not nouns of action
- [ ] No contractions
- [ ] No omitted articles, subjects, or that after make sure / show / recommend
- [ ] No semicolon
- [ ] Multi-word nouns have three words or fewer, or were introduced in full

## Type rules

- [ ] Procedure steps are imperative, one action each, 20 words or fewer
- [ ] Simultaneous actions are the only paired commands
- [ ] Conditions stand before the command and a comma
- [ ] Notes have no imperative and stay at 25 words
- [ ] Description has no imperative, 25-word sentences, one topic per paragraph, six sentences or fewer
- [ ] WARNING vs CAUTION matches injury/death vs equipment damage
- [ ] Each safety instruction has a command or condition plus the result

## Count and consistency

- [ ] Word count uses Section 8 (number+unit, parenthesis, hyphen, abbreviation = one word)
- [ ] Vertical-list lead-in and each bullet stay inside the limit
- [ ] Phrasal verbs are approved or replaced
- [ ] Same task uses the same wording
- [ ] Pronouns have one possible noun
- [ ] with is unambiguous
- [ ] No e.g., i.e., etc.
- [ ] Language is gender-neutral
- [ ] Part numbers, figure callouts, and quoted legends are unchanged
